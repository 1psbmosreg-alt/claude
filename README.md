# Агент: ежедневный мониторинг ИИ в адвокатской деятельности (США)

Агент Claude Code раз в день ищет и проверяет новости об ИИ в юридической практике США
(санкции за вымышленные ссылки, standing orders судов, этические мнения ABA и коллегий штатов,
законодательство, legal-tech) и сохраняет дайджест на русском языке в `digests/`.

- `agent/PROMPT.md` — инструкция агенту (что искать, правила проверки, формат).
- `agent/sources.md` — приоритетные источники.
- `digests/` — ежедневные дайджесты.

## Как запускается

Через **Routine** (запланированный запуск) в Claude Code на claude.ai/code:
каждый день в заданное время создаётся новая облачная сессия с этим репозиторием,
которая выполняет `agent/PROMPT.md`, коммитит дайджест и (опционально) отправляет его в Gmail.

Управление: claude.ai/code → Routines (пауза, изменение времени, запуск вручную).

## Важно

Дайджест — инструмент мониторинга, а не источник для ссылок в процессуальных документах.
Перед использованием любого дела или мнения в документе для суда проверьте его
по первоисточнику и через цитатор (KeyCite / Shepard's).
